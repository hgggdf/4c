文件夹说明：frontend/
====================
本文件夹为项目的前端应用，基于 Vue.js 3 + Vite 构建，提供金融数据可视化、AI 对话、股票分析等交互界面。

文件说明：
- index.html：主 HTML 入口文件。
- package.json：NPM 依赖配置。
- package-lock.json：NPM 依赖锁定文件。
- .env.example：环境变量示例文件。
- vite.config.js：Vite 构建工具配置。

子文件夹说明：
- src/：前端源代码目录，包含组件、页面、路由、状态管理等。
- node_modules/：NPM 依赖安装目录（自动生成，无需手动修改）。
