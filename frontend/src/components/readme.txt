文件夹说明：frontend/src/components/
====================
本文件夹存放可复用的 Vue 组件，提供各类 UI 功能模块。

文件说明：
- AgentTrace.vue：智能体推理过程展示组件。
- ButterflyPanel.vue：蝴蝶效应分析面板。
- ChatBox.vue：聊天输入框组件。
- ChatPanel.vue：聊天对话面板。
- IndustryDetailPanel.vue：行业详情面板。
- IndustryReportPanel.vue：行业研报面板。
- MacroPanel.vue：宏观经济数据面板。
- MessageItem.vue：单条消息展示组件。
- NewsPanel.vue：新闻列表面板。
- PieSelector.vue：饼图选择器组件。
- ReportChart.vue：报告图表组件。
- StockChart.vue：股票走势图表组件。
- StockDetailPanel.vue：股票详情面板。
- StockGrid.vue：股票网格列表组件。

子文件夹说明：
- __tests__/：组件的单元测试。
