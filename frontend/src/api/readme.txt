文件夹说明：frontend/src/api/
====================
本文件夹为 API 请求模块，封装所有与后端服务的 HTTP 通信接口。

文件说明：
- request.js：HTTP 请求基础封装（axios 实例、拦截器、错误处理）。
- analysis.js：分析功能 API。
- announcement.js：公告数据 API。
- butterfly.js：蝴蝶效应分析 API。
- chat.js：聊天对话 API。
- company.js：公司信息 API。
- doc.js：文档相关 API。
- financial.js：财务数据 API。
- macro.js：宏观经济数据 API。
- news.js：新闻数据 API。
- retrieval.js：语义检索 API。
- stock.js：股票数据 API。

子文件夹说明：
- __tests__/：API 模块的单元测试。
