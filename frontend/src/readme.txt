文件夹说明：frontend/src/
====================
本文件夹为前端源代码目录，包含应用的所有业务代码。

文件说明：
- main.js：应用入口文件，初始化 Vue 实例。
- App.vue：根组件，定义应用整体布局。
- styles.css：全局样式文件。

子文件夹说明：
- api/：API 请求模块，封装与后端的 HTTP 通信。
- components/：Vue 组件库，包含可复用的 UI 组件。
- views/：页面组件，对应各路由页面。
- router/：Vue Router 路由配置。
- store/：状态管理（Pinia/Vuex）。
- utils/：工具函数。
- assets/：静态资源文件。
- data/：前端数据文件。
