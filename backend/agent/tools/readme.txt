文件夹说明：backend/agent/tools/
====================
本文件夹为智能体工具集，提供各类金融数据查询和分析能力，供代理在对话中调用。

文件说明：
- announcement_tools.py：公告查询工具，检索上市公司公告信息。
- chart_tools.py：图表工具，生成数据可视化图表。
- company_tools.py：公司信息工具，查询公司基本面数据。
- comparison_tools.py：对比分析工具，支持多公司/多指标对比。
- evidence_tools.py：证据检索工具，为分析结论提供数据支撑。
- financial_tools.py：财务数据工具，查询财报和财务指标。
- macro_tools.py：宏观经济工具，查询宏观经济数据。
- news_tools.py：新闻查询工具，检索金融新闻。
- pharma_decision_tools.py：医药决策工具，辅助医药行业分析。
- registry.py：工具注册表，管理所有可用工具的注册与发现。
- retrieval_tools.py：检索工具，基于向量数据库的语义检索。
- scoring_tools.py：评分工具，对股票或公司进行量化评分。
