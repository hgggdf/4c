文件夹说明：backend/app/router/schemas/
====================
本文件夹存放 API 接口的请求和响应数据模式（Pydantic 模型），用于参数校验和文档生成。

文件说明：
- analysis.py：分析接口的请求/响应模式。
- announcement.py：公告接口的请求/响应模式。
- cache.py：缓存接口的请求/响应模式。
- chat.py：聊天接口的请求/响应模式。
- common.py：通用模式定义（分页、排序等）。
- company.py：公司接口的请求/响应模式。
- financial.py：财务接口的请求/响应模式。
- ingest.py：入库接口的请求/响应模式。
- macro.py：宏观经济接口的请求/响应模式。
- maintenance.py：维护接口的请求/响应模式。
- news.py：新闻接口的请求/响应模式。
- retrieval.py：检索接口的请求/响应模式。
- stock.py：股票接口的请求/响应模式。
