文件夹说明：backend/app/core/database/models/
====================
本文件夹存放 SQLAlchemy ORM 模型定义，每个文件对应一类数据表。

文件说明：
- announcement_hot.py：公告热点数据模型。
- company.py：公司基本信息模型。
- financial_hot.py：财务热点数据模型。
- macro_hot.py：宏观经济热点数据模型。
- news_hot.py：新闻热点数据模型。
- research_report_hot.py：研报热点数据模型。
- user.py：用户模型。
- vector_and_job.py：向量索引与任务模型。
